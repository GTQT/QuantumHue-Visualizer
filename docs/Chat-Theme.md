# 聊天界面设置、配色与快捷功能

聊天面板自带一套独立于页面（商店 / 公告）的「设置」面板：配色只是其中一页，外观、布局和通知也都能调。所有改动实时预览并自动保存，不影响服务器和其他玩家。

## 打开方式

1. 按 `T` 打开聊天面板（与原版聊天相同的入口）。
2. 点击工具栏右侧的「设置」按钮。
3. 面板内按 `ESC` 返回聊天。

## 配色页

- **六种可调颜色**：强调色、面板底色、我的气泡、对方气泡、主文字、次要文字。点选左侧色块后，用右侧 R / G / B 滑条微调，也可以直接读取下方的 `#RRGGBB` 色值。
- **七套预设**：深空、量子青、鎏金、青翠、紫晶、珊瑚、白昼。每套都是完整配色（不只是换强调色），点一下即可整包套用；「白昼」是亮色主题，浅色面板下文字与气泡的对比度同样经过检查。
- **实时预览**：面板右侧的迷你聊天窗口会按当前配色、圆角、透明度和密度即时重绘。

## 外观页

- **面板不透明度**：40% ~ 100%，滑条拖动时聊天面板即时变化。
- **消息密度**：紧凑 / 标准 / 宽松，调整气泡内边距与消息间距。
- **气泡圆角**：直角 / 微圆 / 圆角，聊天气泡与时间分隔条一起变化。
- **时间分隔线**：关闭后不再显示每 5 分钟的时间胶囊，长列表更干净。
- **@提及高亮**：别人在消息里提到你的名字时，气泡会描一圈强调色；搜索命中的气泡则描一圈搜索色。

## 布局页

页面参数同样即时生效，聊天面板会当场重排：

- **面板宽度**：30% ~ 90% 屏幕宽度，还会被 Forge 配置里的最小 / 最大像素宽度夹一次。
- **侧栏宽度**：80 ~ 250 像素；窗口太窄时会自动收紧，不会把消息区挤没。
- **气泡宽度**：45% ~ 100%，100% 表示铺满头像 / 面板留白之后的可用宽度。
- **显示头像**：关闭后不再画玩家头像，省下的横向空间留给气泡。
- **动画速度**：快 / 标准 / 慢，对应 120 / 200 / 320 毫秒的滑入与淡出。

## 通知页

原版聊天栏被聊天面板接管后，游戏内默认看不到新消息；这一页控制的是「玩的时候也不至于错过消息」的最小提示层：

- **HUD 消息**：开启后在屏幕左下角显示最近几条消息的预览条（不挡准星，也不会在打开任何界面时显示）。
- **显示行数**：3 / 5 / 8 行。
- **提示音**：收到私聊或有人 @ 你时播放一声轻响；两种提示音高不同，连续消息有 0.9 秒冷却，不会刷屏。

HUD 只是预览：完整记录、历史与频道切换仍然按 `T` 打开聊天面板。HUD 在最后一条消息过去 10 秒后自动淡出，未读私聊/群消息会以「N 条未读」小胶囊显示。

## 色码分享

- 「复制色码」把当前六色打包成一行文本，例如 `QHC1-6688CC-0E0E16-181830-0E0E22-DDDDDD-999999`。
- 「粘贴色码」从剪贴板读取同样格式的文本并整包套用，格式不对时一个颜色都不会改。
- 色码只包含颜色，不包含不透明度、密度、圆角等外观档位。

## 文件位置

配色与布局保存在 `config/quantumhue/chat_theme.json`（每个客户端各自保存，不影响服务器）。

- 首次启动会从 Forge 配置 `Chat` 分类里的六个颜色字段和面板 / 侧栏宽度播种。
- 只有在手动改过颜色（或布局）之后，Forge 配置里的对应字段才不再覆盖这里的值；在模组配置界面点「完成」会立刻刷新聊天外观，无需重启。
- 「恢复默认」回到深空配色与标准外观、默认布局。

## 顺带的聊天增强

- **搜索**：工具栏「搜索」或 `Ctrl + F`，按消息内容或玩家名过滤，`Enter` 在命中项之间跳转，标题右侧显示命中条数。
- **@ 候选弹窗**：输入 `@` 后自动列出在线玩家，`↑` / `↓` 选择、`Tab` 或 `Enter` 补全、`Esc` 收起；中文输入法下同样可用。
- **Tab 补全**：输入框里按 `Tab` 循环补全 `@玩家名` 和 `:表情`；光标后面的文字会保留。
- **离线私聊留言**：对方不在线时消息会存到服务端的世界存档（`quantumhue/offline_mail.json`），对方上线后按顺序补发；发送者会立刻看到「已留言」或「留言队列已满」的提示。
- **引用回复**：右键消息选择「引用回复」，引用文本压成一行并截断，不会再把换行符原样塞进输入框。
- **时间分隔**：消息按 5 分钟分组显示时间胶囊，颜色跟随当前配色的强调色。
