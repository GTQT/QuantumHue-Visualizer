## 量子色域 — 视界 (QuantumHue Visualizer)

专注于 Minecraft 1.12.2 UI 美化与渲染优化的客户端模组，提供沉浸式、高度可定制的界面体验。

---

### 功能特性

#### 🎨 高级物品提示 (Tooltips)
- 稀有度自适应边框着色，完全可配置的颜色方案
- 物品图标「果冻弹出」弹性动画
- 装备对比系统 —— 并排显示已装备与悬停物品的属性差异
- 分页支持、模组来源标注
- AppleSkin / 神秘时代 / GregTech 集成

#### 💬 自研聊天系统
- **三频道架构**：世界频道 / 私聊 / 群聊，支持自定义网络协议
- **气泡式消息 UI**：暗色半透明面板、玩家头像、时间分隔、刷屏合并
- **表情支持**：内置 50 个常用表情，短码输入（如 `:joy:` `:heart:` `:fire:`），5×10 网格选择器
- **命令分支保护**：命令输入走原版逻辑，不受自定义 UI 影响
- 聊天历史持久化（按世界/服务器分离存储）

#### 📚 内置 Wiki 系统
- Markdown 渲染引擎，支持表格、列表、内联资源
- **LaTeX 公式渲染**（纹理缓存）
- 多方块结构蓝图 3D 预览
- `/wiki` 命令快速打开

#### 📊 IGI 游戏内信息 HUD
- JSON 全配置化布局，支持 25+ 种信息元素
- FPS / TPS / 坐标 / 生物群系 / 光照 / 神秘时代 Vis/Flux 等
- 自由排列、分组、对齐

#### 🌟 现代化启动画面
- 科幻 HUD 风格
- GTQT 齿轮徽记弹出入场动画（可配置时长），随后进入加载读数界面
- **三维戴森球环绕徽记**：测地线结构壳 + 集光板蜂群 + 轨道环能量流，随徽记一同组装
- 徽记独占画面中心，不放文标与副标题；品牌名由 HUD 左上角承担
- 顶部导轨 + 四角支架 + 科技网格 + 扫描带
- 细线进度条 / 堆内存读数 / 启动计时，全部走 HUD 仪器风

#### 🎨 统一背景
- 一份实现，五处共用（`Backdrop`）：**不透明渐变底 + PCB 走线板 + 漂移网格**，自下而上三层
- 覆盖**开机画面、加载页、主菜单、进入世界（读取存档）界面、其它所有菜单**
  （后两者分别经 `LoadingScreenRendererMixin` 与 `ClientHelper.renderPanorama` 驱动）
- 戴森球、HUD、按钮属于前景，由各屏幕自行绘制在背景之上

#### 🖥️ 主菜单接管
- **不借用任何原版画面元素**：全景天空盒整块移除（`renderSkybox` 在 `HEAD` 处取消），
  Minecraft 标题图、Java Edition 缎带、全屏渐变全部停用
- 背景是**三维戴森球**：球心落在屏幕左边缘、只露右半圆、直径等于屏幕高度
- 品牌锁定在右上角（齿轮 + GTQT 字标），导航为右侧仪器台（编号 01–06）
- 全部可在 `QuantumHueConfig` 的 Main Menu 段关闭

#### ⏸️ ESC 暂停界面接管
- **中心圆盘**：暗底 + 下沉井 + 刻度环 + 金色嵌线 + 五段亮弧；井内是**戴森球**（取代参考实现的等高线地形图）
- **左侧四张斜切主卡**（进度 / 统计 / 选项 / 模组设置），**右侧磁贴沿圆盘弧线排布**，**圆盘底部弧形「返回游戏」**
- 左下电源键（悬停才显示标签）、玩家档案卡（皮肤头像 + 等级 + 经验条）、右上世界读数与关闭键
- **手感**：圆盘展开 → 卡片依次飞入 → 磁贴浮现 → 档案卡弹入的开场时间轴，弹簧悬停/按压缩放，
  鼠标视差，拖拽阈值（拖出即视为手势而非点击），收场后才执行动作
- **动作零改动**：全部按钮仍走原版 `actionPerformed`（含 Forge 模组设置、局域网、保存退出），
  Forge `ActionPerformedEvent` 照原位置收发；其它 mod 往暂停菜单加的按钮在 `InitGuiEvent.Post`
  之后自动排进磁贴
- 与参考实现的取舍：**只借布局与运动，不借配色与素材**——图标语汇用矢量基元重画，
  色调沿用 `SplashTheme`；且刻意**不**铺不透明背景，以保留原有关闭时的世界模糊
- **磁贴列可滚轮**：超过四行即可滚轮/拖拽滚动（带惯性、越界回弹、边缘裁切），右侧出现金色滚动条，
  磁贴尺寸不再随按钮数量缩小；滚轮与拖拽走原版 `handleMouseInput` 轮询（1.12.2 的 `GuiScreen` 没有滚动回调）
- **布局自检**：每次重建都跑一遍 `PauseLayout.validate`——角色无卡片、两张卡片占同一格、条目丢 plate、
  槽位出界、条目互相压叠，全部按条目名与序号打进日志（每条只报一次）
- **原版子界面快捷入口**：视频设置 / 按键 / 声音 / 聊天 / 语言 / 资源包 / 皮肤定制 / Snooper 八个原本藏在「选项」里两跳的界面，
  直接作为磁贴挂在右侧；返回键回到本界面（都以本界面为 parent）。可用 `Vanilla Shortcuts` 关闭
- **仪表读数**：顶部一行三组（朝向 + 现实日期时间 + 游戏内天数/时刻/天气）、右下 SYSTEM 面板
  （FPS + 48 帧历史折线 / 堆内存条 / 在线人数 / 实体数 / 视距）、环上难度胶囊、环上出生点方位指针、
  档案卡上方死亡数与下方生命体征、右上世界板含生物群系；**所有数字开场从 0 滚到真值**
- **动效**：画布四角 L 支架 + 沿边框循环的跑马灯、井内旋转扫描扇、悬停弹簧、按压缩放、鼠标视差
- **GTQT Core 集成**：左上角「商店」（`MARKET` 页签）、右上角「公告」（`NEWS` 页签）两块**横幅卡**——金色粗边、\n  骑在边框上的页签、底部金轨、右侧来源标注，与普通卡片刻意不同族（反射构造
  `GuiShop(EntityPlayer, long)` / `GuiAnnouncement()`，无编译依赖；FTB Money 余额反射读取，缺失则传 0，
  打开后由服务端回包校正）；卡片列按实际数量自适应 4→6 张（列高不变，行距与卡高按数量重算）
- 配置项：Pause Menu → 启用 / 动画 / 视差 / 原版快捷入口 / 调试磁贴；窄窗口自动切紧凑布局

#### ✨ 其他视觉增强
- **动态模糊**：打开 GUI 时背景模糊（可配置着色器）
- **平滑滚动**：列表滚动动画，可调速度与弹性
- **主菜单美化**：重设计布局、按钮选中态
- **生物群系提示**：进入新区块时淡入淡出显示群系名
- **中键高亮**：点击方块/实体显示彩色线框轮廓
